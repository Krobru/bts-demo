# Maquette BTS (démo non officielle)

Ceci est une **maquette de démonstration non officielle** d'un site modernisé pour la section BTS de l'UBA, proposée par ON5EE au comité de la section. Elle n'engage ni la section BTS ni l'UBA. Le site officiel reste https://www.bts.uba.be/.

Le site est volontairement exclu des moteurs de recherche (noindex + robots.txt).
